# 前端布局与组件规范（F2 起生效）

> 定位：统一封装的**布局范式 + 组件清单 + 三方库映射**。组件实现一律放 `apps/web/src/components/ui/`（基础）与 `components/common/`（业务通用），页面禁止重复造轮子（docs/06 §7 复用优先）。

## 1. 布局范式（对齐禅道页面结构）

| 范式 | 结构 | 用于 |
| --- | --- | --- |
| **管理台布局** AdminLayout | 左侧固定菜单（权限过滤）+ 顶栏（面包屑/用户/通知）+ 多页签内容区 | 全部业务页面 |
| **列表页** ListPage | PageHeader(标题+主操作) → FilterBar(状态页签+筛选+搜索) → DataTable → Pagination | stories/tasks/bugs/cases/users/… |
| **详情页** DetailPage | DetailHeader(标题+状态Tag+ActionToolbar) → 左主栏(描述/步骤 Markdown) + 右字段面板(DescriptionList+操作日志) | story/task/bug/case/… 详情 |
| **看板页** BoardPage | 泳道×列网格 + 拖拽 + WIP 角标 + 在线头像 | execution board |
| **表单弹窗** FormDialog | Dialog + vee-validate/zod 表单 + 提交按钮 loading | 新建/编辑 |

## 3. 状态标签与动作条（业务组件约定）

- **StatusTag**：`<StatusTag entity="story" :status="story.status" />`——颜色/文案映射集中 `src/types/status.ts`（枚举 import 自 @zentao/shared）
- **ActionToolbar**：动作按钮 = 权限点（v-permission）× isClickable 前置状态（shared TASK_TRANSITIONS 等表）双条件渲染；点击走 useConfirmAction 确认弹窗
- **列表页筛选**：状态页签（各实体 status 枚举）+ 关键字 + 下拉筛选；筛选状态入 URL query（可分享/刷新保持）

## 5. 验收（F2）

- 所有列表页：权限点过滤菜单可见、分页/筛选/状态 Tag 正确、动作按钮按权限×状态渲染
- 所有详情页：动作条按 isClickable 渲染、非法动作后端 3006 时 toast「状态已变化」并刷新
- ego-browser L4：登录→菜单→四层页面逐页走通、截图留档
