## 3. 页面范式（对齐禅道页面结构）

### 3.1 列表页（复刻 product/browse 等）

```
PageHeader(标题 + 描述 + 右侧主操作[创建▾，v-permission])
功能页签（禅道 featureBar 文案：全部/未关闭/指给我/由我创建/各状态；选中=蓝底白字圆角）
筛选行（产品/执行下拉 + 关键字；筛选状态同步 URL query —— useUrlFilter）
el-table（列序按禅道 dtable spec；ID/名称=蓝链接；状态=StatusDot 圆点；P=徽标；指派给=AssignCell 行内指派；操作=灰链接 hover 变蓝，按 isClickable×权限渲染）
表尾（左"共 N 条" + el-pagination）
空态（el-empty + 创建按钮出口；文案"暂时没有××。"）
```

已复刻列序速查：
- **需求**：ID/名称/P/状态/阶段/创建者/预计/指派给/操作
- **Bug**：ID/标题/严重度/P/状态/创建者/创建日期/确认/指派给/解决方案/操作
- **任务**：ID/名称/P/状态/指派给/完成者/截止/预计/消耗/剩余/进度/需求

### 3.2 详情页（复刻 story/view 骨架）

```
标题区：[返回] [#ID 胶囊] [标题 lg bold] [版本号]        ← 状态标签在右栏基本信息内（禅道规则）
左主栏（1fr）：内容块卡（描述/验收标准/评审记录…）+ 历史记录（ActionLogPanel）
右侧栏（320px）：基本信息卡（字段序按禅道 basicinfo）+ 一生卡（由谁创建/指派/评审/关闭/最后修改）
底部悬浮动作栏（sticky）：返回 │ 按 isClickable×权限的状态动作 │ 提需求/提Bug/建任务（primary）
```

### 3.3 表单弹窗

el-dialog + el-form `:rules`（async-validator）；字段序与文案对齐禅道 create 表单；需求创建为**三按钮**：返回 / 存为草稿 / 保存（提审）。

### 3.4 我的地盘（复刻 welcomeblock/assigntomeblock/guideblock/dynamicblock 结构）

日期横幅 → 欢迎格+大数字统计条（`my/summary`）→ 使用帮助（六角色流程链，禅道逐字文案）→ 我的待处理（待办/任务页签）→ 右栏最新动态（站内通知）+ 快捷入口。
**100% 复刻待办**（依赖后端聚合端点）见 §8。

### 3.5 看板页

泳道行 × 顶层列（父列 develop 渲染子列）；sortablejs 拖拽（乐观更新 → Socket ack 回滚，断连走 REST 兜底）；WIP 角标仅警示；presence 头像组。

## 6. 交互边界（全站纪律）

1. **两级到详情**：列表单击标题/ID 进详情；详情内关联对象可点跳转；不用弹窗承载详情。
2. **写操作三型**：纯动作轻确认 / 表单型动作弹表单 / 删除红色确认——统一走 `useConfirmAction`。
3. **权限即不可见**：v-permission 无权限直接移除；菜单/路由/按钮三层。
4. **反馈即时**：成功 toast + 精确失效；失败 toast 服务端 message（如 3006"状态已变化"）；无静默失败。
5. **后端没有的不做**：见 §7 砍除清单。
6. **筛选记忆**：核心列表筛选状态同步 URL query（useUrlFilter）。
7. **零 emoji**：图标一律 @element-plus/icons-vue。
