## 5. 缺陷存档（防复发，全记录见 docs/07）

| 类别 | 样本 |
| --- | --- |
| 契约漂移 | http 层与 store 存储键位不一致（P1）；shared BusinessException 导入错位×3（codemod 根治） |
| 语义双关 | 禅道 parentId 双关致影子执行 close 误报 4603 → grade>1 过滤 |
| 引擎完整性 | setStage 降级保护缺失；setStageFromTasks 漏 none 语义 |
| DTO 纪律 | submitReview/leftHint 未挂校验器被 whitelist 剥离；finish 缺 left |
| 类型/日期 | Date<=string 恒 false（4951 失效）；TS6 ESM 相对导入 .js 后缀 |
| 工程 | tsbuildinfo 双写污染；shared CJS/ESM 双格式致 Rollup 失败（统一 ESM） |
| 前端会话 | 持久化会话不补拉 `/auth/me` → 刷新后权限点为空（ego-browser 走查抓到，守卫补拉修复） |
| 前端认证 | 401 单飞刷新未接入 → raw axios 单飞 + `__retried` 防循环重放 |
| 前端选型 | F2 手绘 cva 基础件违反三方库优先 → Element Plus 整体替换（docs/10 §0 D2） |
| Docker 构建 | 无 .dockerignore（宿主 node_modules/dist 污染镜像）；corepack 漂移 pnpm 12 静默跳过安装（显式钉 10.30.2）；shared 未声明 typescript devDep；runner 漏拷各包 node_modules；compose 缺 JWT_SECRET/.env |
