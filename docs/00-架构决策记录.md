# 架构决策记录（ADR）

> 规则：ADR 只增不改；推翻旧决策时新增一条并在「状态」标注取代关系。
> 格式：编号 ｜ 决策 ｜ 背景 → 结论 ｜ 后果与代价。

| # | 决策 | 结论 | 后果 |
| --- | --- | --- | --- |
| D001 | 工程形态 | **Monorepo**（pnpm workspaces + Turborepo）：apps/server + apps/web + packages/shared | 契约常量（权限点/Socket/枚举/错误码/看板映射）单源共享，漂移在编译期暴露；代价：引入 workspace 构建编排 |
| D002 | 前端 UI | **Vue 3.5 + shadcn-vue + Tailwind**（备选 Element Plus） | 与既有工具链一致、看板类自绘 UI 可控；代价：密集表格场景需自组装 DataTable |
| D003 | 层级数据模型 | 禅道 zt_project 三合一表（program/project/execution）**拆为三表**，但保留 type/grade/parent/path 语义字段 | 外键显式、约束清晰；代价：查询跨层时需 join，无法照抄禅道单表 SQL |
| D004 | 权限模型 | 功能权限 = DB 权限点 (module, action)，与禅道 grouppriv 同构；**JWT payload 不含角色**；鉴权实时查 Redis 缓存 | 可直导禅道权限数据；对齐 nest-admin 成熟模式；代价：权限缓存失效逻辑必须严格 |
| D005 | 数据权限 | 可见对象集合**预计算**（登录/变更时算，Redis 物化，替代禅道 zt_userview 表）；列表查询统一 IN(可见集) | 列表性能可控；代价：缓存一致性依赖失效钩子齐全 |
| D006 | 富文本 | 全实体描述/步骤/文档**统一 Markdown**（md-editor-v3），后端 sanitize-html 白名单清洗 | XSS 面最小、导出友好；代价：无富文本表格等高级格式（禅道 CKEditor 能力收窄，属有意取舍） |
| D007 | 看板数据模型 | 卡片 = 业务对象本体（cell 存 ID 串，对齐禅道三表 lane/column/cell）；**WIP 超限仅前端提示不拦截**；拖拽 = 触发对应任务动作（服务端唯一事实源） | 与禅道行为完全一致、Socket 回滚语义简单；代价：无独立卡片表，卡片级扩展字段（如独立负责人）不支持 |
| D008 | 工时模型 | 统一 zt_effort 单表（objectType 通用，禅道 v22 已废弃 taskestimate）；**记工时隐式驱动任务状态**（left=0→done 等） | 与禅道行为一致、报表维度通用；代价：状态来源多（显式动作+隐式工时），测试矩阵变大 |
| D009 | 管理模型 | project.model **开放枚举**；一期落地 scrum/waterfall/kanban；禅道源码证实无「9 种」枚举（agileplus/waterfallplus/ipd 为专版特性） | 不虚构规格；9 种清单待产品侧确认后按 config 扩展 |
| D010 | 前端路由 | **静态路由表 + 三层权限控制**（菜单过滤/守卫/v-permission），不做动态注册路由 | 简化刷新/收藏/缓存；代价：新页面需发版（管理端可接受） |
| D011 | 通知 | 三通道（站内信 zt_notify / 邮件 / webhook）+ @提及独立解析 + 动作矩阵配置（对齐禅道 message 模块） | 行为对齐禅道；代价：动作矩阵种子需随端点演进维护 |
| D012 | 部署 | docker-compose 四容器（mysql/redis/server/web-nginx）；TypeORM migration 生产禁 synchronize；CI 加权限点漂移校验门禁 | 一键起全栈；代价：迁移纪律必须严格执行 |
| D013 | 代码规范基线 | 以 kb 知识库三篇（《工程流程规范》《前端编码规范》《Vue3 组件开发规范》）为基线，适配后落为 docs/06-代码规范 + prettier/commitlint/husky/.gitattributes 可执行载体 | 继承已验证的实战教训（AI 协作纪律/命名禁令/异步纪律）；适配差异（Tailwind 替代 Less、ApiResponse<T> 替代 PRn、Dto/Vo 替代 BO/VO）显式记录于 06 §0.2 |
