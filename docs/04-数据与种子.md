## 1. 全局约定（适用于所有表）

1. **通用列（不再逐表重复列出）**：每表均有 `id BIGINT UNSIGNED AUTO_INCREMENT PK`、`created_by BIGINT`、`created_at DATETIME`、`updated_at DATETIME`、`deleted TINYINT(1) DEFAULT 0`（软删除）。
2. **外键约定**：全部逻辑外键（索引，不建物理约束）；`xxx_id BIGINT UNSIGNED` + 索引。
3. **类型映射**：禅道 `int unsigned→BIGINT`；`tinyint unsigned→TINYINT`；`decimal(p,s) unsigned→DECIMAL(p,s)`；`text/mediumtext/longtext→TEXT/JSON`（结构化数据用 JSON）；`date→DATE`；`datetime→DATETIME`；枚举一律 `VARCHAR(n)` 存字符串常量。
4. **保留字处理**：`order/left/read/desc/path` 等列名在实体中显式 `@Column({ name })` 映射为 `sort_no/left_hour/is_read/path_str` 等安全名（文档按映射后名称书写）。
5. **枚举值**：标注「（枚举）」的列，取值以《流程细化》对应章节的 lang 枚举为准，代码层用 const 对象集中定义。

```
fails SMALLINT DEFAULT 0               连续登录失败次数
locked_until DATETIME                  锁定截止
client_lang varchar(10) DEFAULT 'zh-cn'
score INT DEFAULT 0                    积分（可选启用）

```

**sys_dept**：`parent_id / path_str varchar(255) 物化路径 / grade TINYINT / name varchar(60) / manager varchar(30)`

**sys_role**：`name varchar(30) / code varchar(30) UNIQUE / is_super TINYINT DEFAULT 0（超管直通）/ remark varchar(255)`
> 项目级角色覆盖不建独立表：sys_user_role 增加 `project_id BIGINT DEFAULT 0`（0=全局授权，>0=仅该项目内生效，解析时优先）。

**sys_user_role**：`user_id / role_id / project_id DEFAULT 0`，UNIQUE(user_id, role_id, project_id)

**sys_permission**：`module varchar(30) / action varchar(30) / name varchar(60) / path varchar(160) / http_method varchar(10) / sort_no INT DEFAULT 0 / status varchar(10) DEFAULT 'active'（active|deprecated）`，UNIQUE(module, action)。种子由控制器扫描生成（见接口清单 §3.1）。

**sys_role_permission**：`role_id / permission_id`，UNIQUE 双列

**sys_acl**（白名单）：`user_id / object_type varchar(30)（program|product|project|execution|kanban）/ object_id BIGINT / source varchar(30)`，KEY(object_type, object_id)

**sys_config**（运行时可配，对齐 zt_config）：`scope varchar(30) DEFAULT 'system'（system|user）/ owner varchar(64) DEFAULT 'system' / module varchar(30) / section varchar(30) / key_name varchar(60) / value TEXT`，UNIQUE(scope,owner,module,section,key_name)。承载 needReview、testcase needReview、uploadType、URI/UR 文案（URSRList）等可配置项（清单见 §9.3）。

**zt_action_history**：`action_id / field varchar(30) / old_value TEXT / new_value TEXT`，KEY(action_id)

**zt_webhook**（P5）：`type varchar(30)（dinggroup/dinguser/wechatgroup/wechatuser/feishugroup/feishuuser/default）/ name / url varchar(500) / secret varchar(255) / actions JSON（订阅动作矩阵）`

**zt_webhook_log**（P5）：`webhook_id / action_id / result varchar(20) / response TEXT / date`

**zt_query**（自定义查询）：`user_id / module varchar(30) / title varchar(90) / params JSON（filter DSL）`，KEY(user_id, module)

**zt_lang**（可配置文案，对齐 zt_lang）：`section varchar(30)（如 custom）/ key_name varchar(100)（如 URSRList）/ value TEXT`——承载 UR/SR 名称自定义等。

**zt_file**：`storage_key varchar(255)（uuid 存储键）/ title varchar(255) / extension varchar(30) / size BIGINT / object_type varchar(30) / object_id BIGINT / extra varchar(100)`

**zt_module**（模块树，需求/用例共用）：`root_id / root_type varchar(10)（product）/ branch_id / parent_id / path_str TEXT / grade TINYINT / name varchar(60) / owner_id / sort_no`

**定时任务**：不建表（禅道 zt_cron 由 `@nestjs/schedule` 代码注册替代：computeburn / computecfd / notify 清理等）。
